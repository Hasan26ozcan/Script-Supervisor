## Limitations (read before citing these numbers)
- Demo dataset uses only two fixed candidate templates repeated across all 20 briefs, so the Bradley-Terry strength gap reflects template style, not per-brief quality.
- One rater per item: no real inter-rater reliability (kappa) is possible on this dataset; collect >=2 raters/item for that.
- heuristic_judge_* metrics come from a deterministic offline text-feature judge, not a live LLM-graded judge -- see module docstring.

## Summary
This report is generated by a statistically grounded pipeline: bootstrap
confidence intervals, a binomial significance test, a Bradley-Terry MLE
fit, and an automated-judge-vs-human agreement check (with Cohen's kappa).
It is intentionally conservative about what the bundled 20-sample demo
dataset can and cannot support -- see the limitations above.
